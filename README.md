# 📌 Blog CMS - Full Stack Project

A full-stack Blog Content Management System built using Spring Boot, React, and MySQL.

---

# 🛠️ Tech Stack

- Java, Spring Boot
- React JS
- MySQL
- REST APIs
- Axios

---

# 📅 Week-wise Progress

## Week 1 - Project Setup & Backend Basics
- Installed and configured Spring Boot project
- Set up MySQL database connection
- Created project structure (Controller, Service, Repository, Model)
- Built User entity and basic setup
- Tested backend setup

---

## Week 2 - Blog Post Module (CRUD APIs)
- Created Post entity (title, content, author, createdAt)
- Built REST APIs for Blog Posts:
  - Create Post
  - Get All Posts
  - Get Post by ID
  - Update Post
  - Delete Post
- Tested APIs using Postman
- Connected Spring Boot with MySQL database

---

## Week 3 - Frontend Development (React)
- Created React application
- Built UI components:
  - Home Page (Post List)
  - Create Post Page
  - View Post Page
- Integrated Axios for API calls
- Connected frontend with backend APIs
- Displayed posts dynamically

---

## Week 4 - Final Features & CMS Completion
- Added Category module
- Added rich text editor
- Improved UI/UX
- Fixed bugs and completed integration
- End-to-end testing completed (Frontend + Backend + Database)

## Frontend
cd blogcms-frontend
npm install
npm start
